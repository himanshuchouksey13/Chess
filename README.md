# Chess-PvP

A simple two-player chess game implemented using HTML, CSS, and JavaScript. This project allows players to play chess in a browser with basic chess rules and functionality. 

## Features
- Fully functional chessboard with all pieces.
- Turn-based gameplay for two players.
- Visual indicators for valid moves.
- Pawn promotion and castling support.
- Highlights the winner when the game ends.

## How to Run the Project

### Prerequisites
- A modern web browser (e.g., Chrome, Firefox, Edge).
- A local server (optional but recommended for better performance).

### Steps to Start the Program
1. **Download or Clone the Repository**:
   - Download the project as a ZIP file and extract it.
   - Or clone the repository using:
     ```bash
     git clone <repository-url>
     ```

2. **Open the Project**:
   - Navigate to the project folder.

3. **Run the Program**:
   - **Option 1: Open Directly in Browser**:
     - Double-click on the `index.html` file to open it in your browser.
   - **Option 2: Run on a Local Server**:
     - Use a local server to serve the files. For example:


         Open `http://localhost:8000` in your browser.
       - Using VS Code Live Server Extension:
         - Install the [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) extension.
         - Right-click on [index.html](http://_vscodecontentref_/15) and select **Open with Live Server**.

4. **Play the Game**:
   - The chessboard will load in your browser. Players can take turns moving pieces by clicking on them.
